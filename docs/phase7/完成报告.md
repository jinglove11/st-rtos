## 架构决策

### Stats 从 Scheduler 解耦

- **问题**: `sched_update_stats()` 在 scheduler.c 中维护 per-task CPU ticks，与调度器逻辑耦合
- **方案**: 创建独立的 `stats.c`/`stats.h`，scheduler 通过 `stats_task_switch()` 和 `stats_tick_update()` 调用
- **兼容**: `sched_get_cpu_usage()` 保留为 thin wrapper

### ELF 解析无外部依赖

- **问题**: pyelftools 需要 pip 安装，嵌入式开发者可能没有
- **方案**: `myrtos_tools.py` 使用纯 Python struct 解析 ELF header，遍历 section header table
- **结果**: Python 3.6+ 即可运行，零外部依赖

### TRACE_BUFFER_SIZE 覆盖问题

- **Bug**: `kernel_config.h` 中 `#define TRACE_BUFFER_SIZE 128` 在 trace.c 之前被 include，导致 trace.c 中的 `#ifndef` 默认值 (256) 被忽略
- **修复**: 同步修改 kernel_config.h、defconfig
