# `VFS_ENABLE`

**Enable Virtual File System**

| Property | Value |
|---|---|
| Type | `bool` |
| Default | `y` |
| Menu path | `VFS Configuration` |

_No dependencies._

## Help

```
启用 VFS 虚拟文件系统。
提供 inode、文件描述符、路径解析，
以及 devfs (设备文件系统) 和 ramfs (内存文件系统)。
```
