# `KERNEL_TASK_STACK_SIZE`

**Default task stack size (bytes)**

| Property | Value |
|---|---|
| Type | `int` |
| Default | `1024` |
| Range | `256 8192` |
| Menu path | `Kernel Configuration` |

_No dependencies._

## Help

```
默认任务栈大小（字节）。
必须是 4 的倍数。
```
