# `SMP_MAX_CPUS`

**Maximum CPU count**

| Property | Value |
|---|---|
| Type | `int` |
| Default | `2` |
| Range | `2 2` |
| Menu path | `Phase 6 — SMP (Cortex-M33 Core 1)` |

- `[SMP](SMP.md)`
