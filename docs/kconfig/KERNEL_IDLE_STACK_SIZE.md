# `KERNEL_IDLE_STACK_SIZE`

**Idle task stack size (bytes)**

| Property | Value |
|---|---|
| Type | `int` |
| Default | `256` |
| Range | `128 1024` |
| Menu path | `Kernel Configuration` |

_No dependencies._

## Help

```
空闲任务栈大小（字节）。
```
