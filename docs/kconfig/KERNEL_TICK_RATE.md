# `KERNEL_TICK_RATE`

**System tick rate (Hz)**

| Property | Value |
|---|---|
| Type | `int` |
| Default | `1000` |
| Range | `100 10000` |
| Menu path | `Kernel Configuration` |

_No dependencies._

## Help

```
系统滴答频率（Hz）。
- 1000 = 1ms per tick（推荐）
- 100 = 10ms per tick
```
