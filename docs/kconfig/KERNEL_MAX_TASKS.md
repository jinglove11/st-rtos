# `KERNEL_MAX_TASKS`

**Maximum number of tasks**

| Property | Value |
|---|---|
| Type | `int` |
| Default | `16` |
| Range | `4 64` |
| Menu path | `Kernel Configuration` |

_No dependencies._

## Help

```
系统支持的最大任务数量。
```
