# `KERN_DEFAULT_TIME_SLICE`

**Time slice (ticks)**

| Property | Value |
|---|---|
| Type | `int` |
| Default | `5` |
| Range | `1 100` |
| Menu path | `Kernel Configuration` |

_No dependencies._

## Help

```
时间片轮转的时间片大小（滴答数）。
设为 0 禁用时间片轮转。
```
