# `CAP_ENABLE`

**Enable capability system**

| Property | Value |
|---|---|
| Type | `bool` |
| Default | `y` |
| Menu path | `Capability Configuration` |

_No dependencies._

## Help

```
启用能力系统 (capability-based access control)。
所有 IPC 对象和内存分配通过能力令牌访问，
提供权限控制和任务间隔离。
```
