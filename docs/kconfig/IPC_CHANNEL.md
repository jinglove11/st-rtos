# `IPC_CHANNEL`

**Enable channel (P2P messaging)**

| Property | Value |
|---|---|
| Type | `bool` |
| Default | `y` |
| Menu path | `IPC Configuration` |

_No dependencies._

## Help

```
启用 Channel 点对点双向通信。
一对一模型，带共享内存区域。
```
