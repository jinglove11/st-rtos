# `SHELL_PRIORITY`

**Shell task priority**

| Property | Value |
|---|---|
| Type | `int` |
| Default | `5` |
| Range | `0 31` |
| Menu path | `Shell Configuration` |

## Dependencies

- `[SHELL_ENABLE](SHELL_ENABLE.md)`

## Help

```
Shell 任务优先级（数值越小优先级越高）。
```
