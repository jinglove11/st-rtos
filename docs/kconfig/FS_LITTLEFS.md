# `FS_LITTLEFS`

**Build littlefs third-party library**

| Property | Value |
|---|---|
| Type | `bool` |
| Default | `n` |
| Menu path | `Phase 4 — Persistent Filesystem` |

## Dependencies

- `[FS_PERSISTENT](FS_PERSISTENT.md)`

## Help

```
把 third_party/littlefs/ 编为 static library。
关闭则 FS_PERSISTENT 无效。
```
