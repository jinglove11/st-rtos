# `KERNEL_MAX_PRIORITIES`

**Number of priority levels**

| Property | Value |
|---|---|
| Type | `int` |
| Default | `32` |
| Range | `8 256` |
| Menu path | `Kernel Configuration` |

_No dependencies._

## Help

```
优先级数量。数值越大，优先级越低。
```
