# `SHELL_ENABLE`

**Enable interactive shell**

| Property | Value |
|---|---|
| Type | `bool` |
| Default | `y` |
| Menu path | `Shell Configuration` |

_No dependencies._

## Help

```
通过串口终端提供交互式 shell。
测试完成后自动启动。
```
