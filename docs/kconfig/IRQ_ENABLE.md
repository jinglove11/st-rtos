# `IRQ_ENABLE`

**Enable interrupt management**

| Property | Value |
|---|---|
| Type | `bool` |
| Default | `y` |
| Menu path | `Interrupt Configuration` |

_No dependencies._

## Help

```
启用 ISR 注册、底半部和线程化 IRQ 支持。
```
