# `IRQ_MAX_USER`

**Maximum registered ISRs**

| Property | Value |
|---|---|
| Type | `int` |
| Default | `16` |
| Range | `1 64` |
| Menu path | `Interrupt Configuration` |

## Dependencies

- `[IRQ_ENABLE](IRQ_ENABLE.md)`

## Help

```
最大可注册的用户中断处理函数数量。
```
