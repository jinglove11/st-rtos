# `IRQ_THREADED_MAX`

**Maximum threaded IRQs**

| Property | Value |
|---|---|
| Type | `int` |
| Default | `4` |
| Range | `1 16` |
| Menu path | `Interrupt Configuration` |

## Dependencies

- `[IRQ_THREADED_ENABLE](IRQ_THREADED_ENABLE.md)`

## Help

```
最大线程化 IRQ 槽位数。
```
