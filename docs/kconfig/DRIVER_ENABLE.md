# `DRIVER_ENABLE`

**Enable device driver framework**

| Property | Value |
|---|---|
| Type | `bool` |
| Default | `y` |
| Menu path | `Driver Configuration` |

## Dependencies

- `[VFS_ENABLE](VFS_ENABLE.md)`

## Help

```
启用设备驱动框架。
提供 device_t 抽象层, 驱动自动注册到 devfs。
```
