# `KERNEL_IDLE_PRIORITY`

**Idle task priority**

| Property | Value |
|---|---|
| Type | `int` |
| Default | `31` |
| Range | `0 255` |
| Menu path | `Kernel Configuration` |

_No dependencies._

## Help

```
空闲任务优先级（数值越大优先级越低）。
```
