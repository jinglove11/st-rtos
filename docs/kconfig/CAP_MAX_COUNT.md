# `CAP_MAX_COUNT`

**Maximum capability entries**

| Property | Value |
|---|---|
| Type | `int` |
| Default | `32` |
| Range | `8 128` |
| Menu path | `Capability Configuration` |

## Dependencies

- `[CAP_ENABLE](CAP_ENABLE.md)`

## Help

```
全局能力池大小。每个 IPC 对象和内存
分配占用一个能力槽位。
```
