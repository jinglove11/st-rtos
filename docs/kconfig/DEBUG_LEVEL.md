# `DEBUG_LEVEL`

**Debug level**

| Property | Value |
|---|---|
| Type | `int` |
| Default | `2` |
| Range | `0 3` |
| Menu path | `Debug Configuration` |

## Dependencies

- `[DEBUG_ENABLE](DEBUG_ENABLE.md)`

## Help

```
调试级别：
0 = 无输出
1 = 错误
2 = 警告
3 = 信息
```
