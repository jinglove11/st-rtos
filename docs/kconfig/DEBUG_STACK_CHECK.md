# `DEBUG_STACK_CHECK`

**Enable stack overflow check**

| Property | Value |
|---|---|
| Type | `bool` |
| Default | `y` |
| Menu path | `Debug Configuration` |

_No dependencies._

## Help

```
启用栈溢出检测。
在任务栈底填充魔数，检测栈溢出。
```
