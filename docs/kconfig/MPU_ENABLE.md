# `MPU_ENABLE`

**Enable MPU memory protection**

| Property | Value |
|---|---|
| Type | `bool` |
| Default | `y` |
| Menu path | `Microkernel Configuration` |

_No dependencies._

## Help

```
启用 Cortex-M7 MPU 内存保护。
用户任务运行在非特权模式，MPU region 隔离内存访问。
这是微内核安全隔离的基础。
```
