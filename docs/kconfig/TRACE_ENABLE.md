# `TRACE_ENABLE`

**Enable kernel event tracing**

| Property | Value |
|---|---|
| Type | `bool` |
| Default | `y` |
| Menu path | `Kernel Configuration` |

_No dependencies._

## Help

```
启用内核事件追踪。
记录任务切换、中断、系统调用等事件到环形 buffer。
shell `trace` 命令可查看最近事件。
```
