# `IRQ_THREADED_STACK_SIZE`

**Threaded IRQ handler stack size (bytes)**

| Property | Value |
|---|---|
| Type | `int` |
| Default | `512` |
| Range | `256 2048` |
| Menu path | `Interrupt Configuration` |

## Dependencies

- `[IRQ_THREADED_ENABLE](IRQ_THREADED_ENABLE.md)`

## Help

```
线程化 IRQ 处理任务的栈大小。
```
