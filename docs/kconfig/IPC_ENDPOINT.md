# `IPC_ENDPOINT`

**Enable endpoint (C/S messaging)**

| Property | Value |
|---|---|
| Type | `bool` |
| Default | `y` |
| Menu path | `IPC Configuration` |

_No dependencies._

## Help

```
启用 Endpoint 客户端-服务器消息传递。
多对一模型：多个客户端发送请求，服务端接收并回复。
```
