# `KERN_TASK_NAME_LEN`

**Task name length**

| Property | Value |
|---|---|
| Type | `int` |
| Default | `16` |
| Range | `8 64` |
| Menu path | `Kernel Configuration` |

_No dependencies._

## Help

```
任务名称最大长度。
```
