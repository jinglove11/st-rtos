# `MEM_DYNAMIC`

**Enable dynamic memory allocation**

| Property | Value |
|---|---|
| Type | `bool` |
| Default | `y` |
| Menu path | `Memory Configuration` |

_No dependencies._

## Help

```
启用动态内存分配（malloc/free）。
```
